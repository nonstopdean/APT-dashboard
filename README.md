# 아파트 실거래가 대시보드 (배포용)

국토교통부 "아파트 매매 실거래가 자료" 공개 API를 서버(Next.js API Route)에서 대신 호출해서
브라우저의 CORS 제약 없이 보여주는 대시보드입니다. 개인/비상업 용도로 무료 배포가 가능합니다.

## 로컬에서 먼저 테스트 (선택)

```bash
npm install
cp .env.local.example .env.local
# .env.local 파일을 열어서 MOLIT_SERVICE_KEY 값을 채워넣기
npm run dev
```

브라우저에서 http://localhost:3000 접속해서 정상 작동하는지 확인합니다.

## 실제 배포하기 (GitHub + Vercel)

### 1. GitHub에 코드 올리기

이 폴더에서:

```bash
git init
git add .
git commit -m "init: apt market dashboard"
```

GitHub에서 새 저장소를 만든 뒤 (Private 선택 가능), 안내되는 명령어로 push:

```bash
git remote add origin <본인의 저장소 URL>
git branch -M main
git push -u origin main
```

`.env.local`은 `.gitignore`에 포함되어 있어 절대 GitHub에 올라가지 않습니다. 서비스키는
안전합니다.

### 2. Vercel에 배포

1. https://vercel.com 에서 GitHub 계정으로 로그인
2. "Add New..." → "Project" → 방금 올린 저장소 선택
3. Framework Preset은 Next.js가 자동 감지됩니다. 그대로 진행
4. 배포 전에 "Environment Variables" 항목에 아래를 추가:
   - Key: `MOLIT_SERVICE_KEY`
   - Value: 공공데이터포털에서 발급받은 서비스키 (Decoding 형태)
5. "Deploy" 클릭 → 1~2분 후 `https://프로젝트명.vercel.app` 형태의 실제 URL 생성

이후로는 이 URL로 접속할 때마다 서버가 국토부 API를 대신 호출해서 최신 데이터를 보여줍니다.

### 3. 코드 수정 후 재배포

코드를 고치고 싶으면 파일을 수정한 뒤:

```bash
git add .
git commit -m "수정 내용"
git push
```

Vercel이 push를 감지해서 자동으로 재배포합니다.

## 전월세(전세/월세) 데이터 사용하려면

대시보드 왼쪽에서 "전월세"를 선택하면 `/api/rents`가 호출되는데, 이건 매매와
**다른 데이터셋**이라 공공데이터포털에서 별도로 활용신청이 필요할 수 있습니다.

1. data.go.kr에서 **"국토교통부_아파트 전월세 실거래가 자료"** 검색
2. 해당 데이터 페이지에서 **활용신청** (자동승인)
3. 이미 매매 API에 쓰던 서비스키를 그대로 쓰면 됩니다 (계정은 같고, 데이터셋별 승인만 추가되는
   구조입니다)

전월세 선택 시 "등록되지 않은 서비스키" 같은 에러가 뜨면, 이 활용신청을 아직 안 하셨을
가능성이 가장 높습니다.

## 시세동향(한국부동산원 R-ONE) 사용하려면

"시세동향" 토글은 국토부 실거래가와는 완전히 다른 기관(한국부동산원)의 표본조사 통계
API를 씁니다. 별도 계정/키가 필요합니다.

1. https://www.reb.or.kr/r-one 에서 회원가입 후 로그인
2. Open API > 인증키 발급 (마이페이지에서 발급 내역 확인 가능)
3. 발급받은 키를 Vercel 환경변수 `RONE_SERVICE_KEY` 에 등록 (MOLIT_SERVICE_KEY와는 별개)

**주의사항**
- 이 API는 CORS를 지원하지 않아 브라우저 직접 호출이 불가능합니다 — 그래서 서버(API
  라우트)에서 대신 호출하도록 만들어져 있습니다.
- 지역은 국토부 실거래가의 법정동코드가 아니라 R-ONE 자체 지역코드(CLS_ID)를 씁니다.
  `lib/rone-regions.js`에 매핑을 넣어뒀지만, 최근 행정구역이 바뀌었거나 통계 표본에
  없는 일부 군 지역은 매핑이 없을 수 있습니다 (사이트에서 "미지원"으로 표시됨).
- 이 통계는 실제 거래가 아니라 **표본조사 기반 평균값**이라, 실거래가 API의 숫자와
  차이가 날 수 있습니다.

## 시/도 전체(서울 전체, 부산 전체 등) 조회

지역 선택 드롭다운의 "시/도 전체" 그룹을 고르면, 매매/전월세 탭에서는 서버가 그
시/도에 속한 모든 시/군/구를 대신 호출해서 합산합니다. 국토부 API 자체가 시/군구
단위로만 조회되기 때문에, "서울 전체" 하나를 선택해도 실제로는 25번 호출이 나갑니다.

- 지역 수 × 개월 수가 커질수록 느려집니다. 시/도 전체를 쓸 때는 기간을 3~6개월
  정도로 시작해보세요.
- Vercel 함수 실행 제한 때문에 너무 많은 지역 x 기간 조합은 타임아웃이 날 수
  있어요. API 라우트에 `maxDuration = 60`을 설정해뒀지만, 플랜에 따라 실제
  허용 시간이 다를 수 있습니다.
- "시세동향(한국부동산원)" 탭은 원래 통계 자체에 시/도 롤업 수치가 있어서
  호출 1번으로 끝나 훨씬 빠릅니다.

## 서울 지도에 카카오맵 얹기 (선택)

`RONE_SERVICE_KEY`처럼 필수는 아니고, 안 넣으면 자동으로 색칠된 SVG 지도가 대신
나옵니다. 진짜 거리/확대축소가 되는 지도 위에 색을 얹고 싶으면:

1. https://developers.kakao.com 에서 애플리케이션 생성
2. 앱 설정 > 앱 키에서 **JavaScript 키** 복사
3. **플랫폼 > Web 플랫폼 등록**에 배포된 사이트 도메인을 정확히 추가
   (예: `https://apt-dashboard-five.vercel.app`) — 이걸 안 하면 지도가 안 뜹니다
4. Vercel 환경변수에 `NEXT_PUBLIC_KAKAO_MAP_KEY` 로 등록 후 재배포

`NEXT_PUBLIC_` 접두사가 붙은 값은 브라우저에 그대로 노출되는 값이라, 비밀키가 아니라
"이 도메인에서만 쓸 수 있게 막아두는" 방식으로 보안을 거는 키입니다. 3번의 도메인 등록이
그 역할을 합니다.

## 가격 변동 알림 설정하기

매일 자동으로 관심 지역 평당가를 확인해서, 변동폭이 크면 디스코드로 알려줍니다.

1. **디스코드 웹훅 만들기**: 디스코드 채널 설정(톱니바퀴) > 연동 > 웹훅 > 새 웹훅 만들기 >
   "웹훅 URL 복사". 이 URL을 `DISCORD_WEBHOOK_URL` 환경변수에 등록.
2. **저장소 연결 (Vercel Marketplace)**: Vercel이 최근에 "KV"라는 이름을 없애고
   Marketplace 방식으로 바꿨습니다. Vercel 프로젝트 > **Storage** 탭 > 아래쪽
   **Marketplace Database Providers**에서 **Upstash**(또는 "Redis") 찾아서 **Create/Install**
   → 몇 가지 옵션(지역 등) 선택하고 생성 → 이 프로젝트에 **Connect**. 연결하면 환경변수가
   자동으로 추가되는데, 이름이 `KV_REST_API_URL`/`KV_REST_API_TOKEN`일 수도 있고
   `UPSTASH_REDIS_REST_URL`/`UPSTASH_REDIS_REST_TOKEN`일 수도 있어요 (둘 다 코드에서
   자동으로 인식하게 만들어뒀으니, 연결만 되면 이름은 신경 안 쓰셔도 됩니다).
3. **관심 지역 설정**: `ALERT_REGIONS` 환경변수에 지역 코드를 콤마로 구분해서 등록
   (예: `11680,11650`). 변동 기준(%)은 `ALERT_THRESHOLD_PCT` (기본 1).
4. 재배포하면 `vercel.json`에 등록된 크론 작업이 매일 자정(UTC, 한국시간 오전 9시)에
   자동 실행됩니다.

**직접 테스트하고 싶으면**: 배포 후 `https://내사이트주소/api/check-alerts`에 브라우저로
접속해서 바로 실행해볼 수 있습니다 (처음 실행은 "최초 기록"만 하고, 그 다음 실행부터
비교가 시작됩니다).

**보안 참고**: `CRON_SECRET` 환경변수를 설정해두면, 이 값을 모르는 사람이 임의로
`/api/check-alerts`를 호출해도 거부됩니다 (Vercel Cron은 자동으로 이 값을 붙여서
호출합니다). 설정 안 해도 동작은 하지만, 아무나 URL을 눌러 강제로 알림을 울릴 수 있는
점은 참고해주세요.

## 참고 및 주의사항

- **무료 사용량**: 이 API는 개발계정 기준 하루 트래픽 한도가 있습니다 (보통 10,000건). 개인
  사용으로는 충분합니다.
- **응답 시간**: Vercel 무료(Hobby) 플랜은 서버 함수 실행 시간이 최대 10초로 제한됩니다.
  지역을 너무 많이 선택하거나 기간을 12개월로 길게 잡으면 타임아웃이 날 수 있어요. 처음엔
  지역 3~5개, 기간 6개월 정도로 테스트해보세요.
- **비상업적 용도**: 국토교통부 실거래가 데이터는 공공데이터포털 이용약관에 따라 이용해야
  합니다. 개인적으로 시세를 확인하는 용도로는 문제없지만, 이 데이터를 유료 서비스나 재판매
  형태로 활용하려면 별도로 이용약관과 활용신청 조건을 다시 확인하세요.
- **서울 외 지역**: 기본으로 서울 25개 자치구 코드만 정확히 넣어뒀습니다. 다른 지역은
  code.go.kr에서 법정동코드 앞 5자리를 확인해서 대시보드의 "지역 코드 직접 추가"로
  넣으면 됩니다.
